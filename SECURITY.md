# Security policy

Security fixes apply to the current `main` branch of this Cubbie frontend repository.

## Reporting

Do not disclose sensitive vulnerability details in a public issue or pull request. If private vulnerability reporting is enabled, use the repository's GitHub Security reporting form. Otherwise, contact the maintainer privately before sharing details. Do not include credentials, account data, or personal information in a report.

Include the affected code or dependency, the potential impact, safe reproduction steps, and any suggested mitigation.

## Scope

Reports may cover this repository's frontend code, dependencies, build configuration, and helper scripts. External Cubbie services and unrelated third-party services are outside this repository's security scope.

The frontend demo does not provide backend account operations and must not store credentials or secrets.
